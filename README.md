# personal-web-apps

自分専用の単体HTMLウェブ道具の保管・版管理リポジトリ。開発は 甘山愛那（Muse）と持ち主の共同作業。

## 収録物

- `index.html` — 道具の一覧ページ
- `pdf-pair-desk-unified.html` — PDF Pair Desk（PDF比較・注釈・画像化）。構築・検証用のソース一式はワークスペースの ~/workspace/projects/pdf-pair-desk-unified/ にある

## 運用

- 道具が増えたら、ファイルを追加して `index.html` の一覧に1行足す
- GitHub Pages の有効化は未実施（private リポジトリのため無料プランでは使えない。公開可否は道具ごとに判断する）
