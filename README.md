# personal-web-apps

自分専用の単体HTMLウェブ道具の保管・版管理リポジトリ。開発は 甘山愛那（Muse）と持ち主の共同作業。

## 収録物

- `index.html` — 道具の一覧ページ
- `pdf-pair-desk-unified.html` — PDF Pair Desk（PDF比較・注釈・画像化）。構築・検証用のソース一式はワークスペースの ~/workspace/projects/pdf-pair-desk-unified/ にある

## 公開

- 2026-11-12、持ち主の判断でこのリポジトリのみ public に変更し、GitHub Pages を有効化した。他のリポジトリ（Ayana-s-Diary、Outputs-by-Ayana、kancolle-ai-assistant）は private のまま
- 公開ページ: https://robomaskboy.github.io/personal-web-apps/
- 公開してよいのは、個人を特定する情報を含まない道具だけ。新しい道具を入れる前に中身を確認する

## 運用

- 道具が増えたら、ファイルを追加して `index.html` の一覧に1行足す
